# MAYA — односторінковий сайт

Адаптивний сайт українською: сантехніка, електрика, сонячні панелі. Головна дія — дзвінок, друга — запит вартості.
Стек: Vite + TypeScript, без фреймворка, без бекенду. HTML збирається з одного конфігу під час збірки, тому весь контент є у готовому HTML без JavaScript.

## Запуск

```bash
npm install
npm run dev        # розробка, http://localhost:5173
npm run build      # typecheck + продакшн-збірка у dist/
npm run preview    # перегляд dist/
npm run typecheck
npm run lint
npm test           # тести валідації телефону
```

## Як відкрити на Mac/Windows

Потрібен [Node.js](https://nodejs.org) 20 або новіший (для `npm test` потрібен Node 22.18+). Відкрийте термінал (Mac: Terminal, Windows: PowerShell) у папці проєкту й виконайте:

```bash
npm install        # один раз, ставить залежності
npm run dev        # режим розробки, відкрийте http://localhost:5173
npm run build      # збирає готовий сайт у папку dist/
npm run preview    # перегляд зібраного сайту, адреса з'явиться в терміналі
```

**Відкрити `dist/` без сервера.** Після `npm run build` двічі клацніть `dist/index.html`: сайт відкриється у браузері з усіма стилями, шрифтами й зображеннями. Для цього збірка не використовує `type="module"` та `crossorigin` (браузери блокують їх на `file://`), а всі шляхи відносні. Папку `dist/` можна також перенести цілою, наприклад на флешку або в підпапку хостингу.

Якщо щось не відкривається: перевірте `node -v` (має бути 20+), видаліть папку `node_modules` і повторіть `npm install`. Не відкривайте `index.html` з кореня проєкту (це шаблон для розробки, а не готова сторінка): потрібен саме `dist/index.html` або `npm run dev`.

## Деплой на статичний хостинг

`npm run build`, далі завантажте вміст `dist/` на статичний хостинг. GitHub Actions збирає сайт і завантажує `dist/` на Apache-сервер через FTPS. Файл `public/.htaccess` потрапляє в корінь `dist/` і задає кешування: один рік для хешованих Vite CSS/JS та шрифтів, 30 днів для зображень і відео, повторну перевірку HTML. Для правил кешу потрібен увімкнений Apache `mod_headers`; якщо хостинг його вимикає, задайте ті самі заголовки в панелі хостингу.

Якщо домен проксійовано через Cloudflare, встановіть Browser Cache TTL на **Respect Existing Headers**. Не кешуйте HTML на рік: він має проходити повторну перевірку, щоб браузер отримав актуальні імена хешованих файлів після деплою. Для `/assets/*` можна ввімкнути довге кешування, оскільки імена збірок змінюються разом із вмістом. Cloudflare Pages `_headers` тут не використовується: поточний workflow розгортає сайт на Apache через FTP.

Шляхи відносні (`base: './'`), тому збірка працює з кореня і з підпапки.

## Що де змінювати

Усе в `src/config/site.ts`:

| Що | Де |
| --- | --- |
| Назва й слоган | `site.name`, `site.tagline` |
| Телефони | `site.phones.andriy` (кожен: `name`, `display`, `e164`) |
| Номер Олеся | `site.phones.oles`; показати: `site.flags.showOlesPhone = true` |
| Послуги | масив `services` (`id`, `category`, `title`, `description`, `icon`) |
| Розділи «Чому ми», «Як замовити», FAQ | `whyUs`, `steps`, `faq` |
| Домен | `site.domain` (тоді додаються canonical і og:url) |

Іконки: `src/config/icons.ts`. Кольори й шрифт: змінні на початку `src/styles.css`.
SEO-заголовок і опис: `meta` у `src/render.ts`.

### Сонячні панелі

Послуги з сонячних панелей **не підтверджені власником**. Поки `site.flags.solarConfirmed = false`, показується лише коротка нейтральна картка «Зателефонуйте, щоб обговорити завдання», без переліку послуг. Щоб увімкнути перелік: перевірте або виправте три послуги в `services` (категорія `solar`) і поставте `solarConfirmed: true`. Не додавайте марки обладнання, потужності, терміни окупності чи юридичні твердження, поки власник їх не підтвердить.

## Зображення

Усі зображення локальні, у `public/img/`. Це оригінальні SVG-ілюстрації: `hero.svg` (головний екран, позначений на сторінці як ілюстрація). Галерея "Наші роботи" бере реальні фото й відео з `public/work/` (список у `works` в `src/config/site.ts`).
Щоб замінити на реальні фото або банери власника: покладіть оптимізовані `.webp` (або `.avif` із запасним `.jpg`) у `public/img/`, і змініть `src` у `src/render.ts` (`hero()` та `gallerySection()`, а також масив `gallery` у конфігу). Залиште `width`/`height` і змістовний `alt`, використовуйте `srcset` для кількох розмірів. Не вставляйте розмиті скриншоти.

## Форма

Бекенду немає, тому форма **нікуди нічого не надсилає**. Вона перевіряє номер (український формат), а потім показує кнопку «Зателефонувати» та посилання `sms:` із готовим текстом. Це чесно позначено у відповіді форми.

Підключення справжньої відправки: уся логіка в `src/lib/submit.ts`, функція `submitInquiry`.
1. Простий варіант: виберіть сервіс, що приймає JSON POST (власний сервер, serverless-функція, Formspree тощо), і вкажіть його адресу в `site.formEndpoint`. Тоді форма надсилатиме `{name, phone, category, service, description}` і покаже «Звернення надіслано» лише за відповіді 2xx.
2. Це передача персональних даних сторонньому сервісу: перевірте його умови й за потреби додайте на сайт повідомлення про обробку даних.
3. Для іншого каналу (месенджер, CRM) замініть тіло `submitInquiry`, зберігши тип `SubmitResult`.

## Відомі обмеження

- Номер Олеся й сонячні послуги чекають підтвердження власника (див. вище).
- Немає адреси, графіка роботи, цін, відгуків: їх не вигадано, і їх немає в мікророзмітці. Додавайте лише перевірені факти.
- Немає `og:image` (потрібне растрове зображення, наприклад 1200×630 PNG/JPG). Додайте його разом із реальним банером.
- `robots.txt` дозволяє індексацію та вказує на `sitemap.xml`; оновлюйте `<lastmod>` лише після суттєвої зміни сторінки. Канонічна адреса — `https://santehnik-cherkasy.com/`.
- Анімація підкреслень у заголовку вимикається при `prefers-reduced-motion`.
- Шрифт Manrope підключено через npm-пакет `@fontsource-variable/manrope` і віддається з власного домену.
